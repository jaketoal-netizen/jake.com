1. Ternary operator

Return 'Even' for an even number and 'Odd' otherwise, using a ternary.

function getEvenOrOdd(number) {
  return number % 2 === 0 ? 'Even' : 'Odd';
}

The remainder operator % gives what remains after division. An even number divided by 2 has a remainder of 0. A ternary follows the pattern condition ? valueIfTrue : valueIfFalse.

Key point: A ternary is a compact expression for choosing between two values. Use a normal if when the branches require several actions.

2. Truthy, falsy, and the NOT operator

Return false for an empty string or undefined, and true otherwise.

function hasUsername(username) {
  return !!username;
}

JavaScript treats '' and undefined as falsy. One ! reverses the truthiness; the second reverses it back and produces an actual boolean.

Worth remembering: Common falsy values are false, 0, '', null, undefined, and NaN. Strings such as '0' and 'false' are truthy because they are not empty.

3. Default value with OR

Use the supplied currency, or fall back to 'GBP' when it is not usable.

function chooseCurrency(currency) {
  return currency || 'GBP';
}

The OR operator returns the first truthy operand. If currency is empty or missing, JavaScript continues to 'GBP'.

Extra context: || replaces every falsy value. When only null and undefined should trigger a fallback, modern JavaScript uses ?? instead.

4. String property and method

Return an object containing the word's character count and its uppercase form.

function inspectWord(word) {
  return {
    length: word.length,
    uppercase: word.toUpperCase()
  };
}

.length is a property containing a value, so it has no parentheses. .toUpperCase() is a method that performs an action, so it needs parentheses.

Common mistake: Writing word.length() causes an error because length is not a function. String methods return new strings; they do not alter the original string.

5. Nested objects and bracket notation

Log 'Next day' with bracket notation, then access the nested rating of 4.8.

console.log(order['delivery-time']);
console.log(order['rating']['stars']);

The hyphen in 'delivery-time' prevents ordinary dot notation, so brackets are required. Each extra level in an object needs another property access.

Alternative: The second line could be order.rating.stars. Brackets are particularly useful for unusual property names or a property name held in a variable.

6. Object destructuring

Create title and year variables from the supplied film object.

const { title, year } = film;
console.log(title);
console.log(year);

Destructuring pulls named properties out of an object. It is a shorter version of writing const title = film.title and const year = film.year.

Key point: Object destructuring matches property names, not their position. You can write the names in either order.

7. Add and delete object properties

Add isActive: true and remove temporaryCode.

account.isActive = true;
delete account.temporaryCode;
console.log(account);

Assigning to a property that does not yet exist adds it. The delete operator removes a property.

Important: An object declared with const can still have its contents changed. const prevents assigning an entirely different object to the variable.

8. JSON conversion

Convert the settings object to JSON text and then restore it to an object.

const settingsJSON = JSON.stringify(settings);
const restoredSettings = JSON.parse(settingsJSON);

JSON.stringify serializes a JavaScript value into text. JSON.parse reads valid JSON text and constructs a JavaScript value.

Why this matters: Storage and network requests commonly work with text. JSON provides a standard way to represent data, but it cannot directly preserve methods or values such as undefined.

9. localStorage

Save 'Jake', retrieve it, log it, and remove it.

localStorage.setItem('testUsername', 'Jake');
const savedUsername = localStorage.getItem('testUsername');
console.log(savedUsername);
localStorage.removeItem('testUsername');

setItem saves a key/value pair, getItem retrieves it, and removeItem deletes it.

Important: localStorage stores strings. To store an object, first use JSON.stringify; after retrieving it, use JSON.parse. Data normally remains after a page refresh until it is removed.

Bonus: Random choice

Randomly return 'Red' or 'Blue'.

function pickRandomColour() {
  const number = Math.random();
  return number < 0.5 ? 'Red' : 'Blue';
}

Math.random() returns a number from 0 (inclusive) up to 1 (exclusive). Splitting at 0.5 gives each answer roughly a 50% chance.

Key point: Random does not mean alternating. The same colour can legitimately appear several times in a row.
